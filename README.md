# 事務事業評価 事業一覧ツール作成

自治体が公表している事務事業評価シート（PDF）から「事業の一覧」を作り、住民が事業ごとに 👍（良い）・👎（悪い）で投票し、コメントできる評価ツール（HTMLファイル1つ）を書き出すツールです。

- 作成ツール：https://onuma-spec.github.io/jimujigyou-hyoka-list/
- 公開例（静岡県湖西市 令和7年度）：https://onuma-spec.github.io/jimujigyou-hyoka-list/jimujigyou_22221_2025.html

書き出した評価ツールは、自治体が公表している評価シートをもとに民間で作成するもので、自治体の公式なものではありません。評価ツールの見出しとフッターにも、その旨が自動で表示されます。

要約や分類は行いません。評価の判断材料は、自治体が公表している評価シートそのものです。書き出す評価ツールにはPDFを含めず、各事業から自治体サイトの評価シートの該当ページへリンクします。

## 使い方
作成ツールをブラウザで開き、画面の①〜⑤の順に進めます（パソコンでの作業を想定しています）。

1. **評価シートPDFから**：自治体サイトから評価シートのPDFをダウンロードして読み込み、各PDFのURLを入力します
2. **事業一覧を作り（行）**：各事業の評価シートの1枚目にだけ印字されている文字（シート名など）で全ページを探し、見つかったページを一覧の行にします
3. **事業一覧を作り（中身）**：事業名の直前に印字されているラベル（例：「事務事業名」）を入力して事業名を取り出し、必要なら補足（担当課など）を入れ、事業ではない行を消します
4. **住民が投票できる**：投票データの保存先を選びます（下記）
5. **評価ツール（HTMLファイル1つ）を書き出します**：書き出したHTMLをGitHub Pagesなどで公開し、住民にURLを共有します

書き出したHTMLは、あとで修正するときに必要なので保管してください。作成ツールの最初の画面で「前回作ったHTMLから作り直す」に読み込むと、集まった投票・コメントを引き継いだまま修正できます。

読み込んだPDFは、お使いのブラウザの中だけで処理され、どこにも送信されません。

## 投票データの保存先
- **共有の送信先**（既定）：このツールの作者が管理するスプレッドシートに保存されます。評価ツールごとの識別キー（tool_id）で区別されます。
- **自分のスプレッドシート**：作成ツールの④から「ひな形」のスプレッドシートをコピーし、Apps Scriptをウェブアプリとして公開すると、自分のGoogleドライブに保存できます。受け付けのプログラムは `gas/Code.gs`、手順は `gas/公開手順.md` にあります。

住民の投票は、端末ごとのランダムな識別番号で区別し、同じ端末から送り直した場合は最新の評価だけを数えます。氏名などの個人情報は収集しません。コメントに電話番号・メールアドレス・URL・氏名を明示する表現が含まれる場合は送信できません。
